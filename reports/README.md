# Reports

`latest.json` is read by the dashboard.

`latest.md` is a human-readable summary.

`validation.json` contains the next-session-open, cost-adjusted forward-validation ledger and summary.

`security-audit.json` records source-domain, secret-pattern, action-pin and vendored-asset checks.

`shared/manifest.json` describes the reusable full-market feeds. `shared/jp-base.json` and `shared/us-base.json` contain compact base metrics for every screened symbol, while `shared/technical-top.json` is the lighter ranked feed for user interfaces.
